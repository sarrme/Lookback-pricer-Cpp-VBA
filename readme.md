# Lookback Option Pricer based on Monte Carlo Approach

## 📌 Description

This project implements a **Lookback Option Pricer** using a Monte Carlo simulation approach. It calculates both the **option price** and associated **Greeks**, and displays the **Price** and **Delta curves** as a function of the underlying price at time zero.

The project consists of:
- A **C++ implementation** using Visual Studio.
- A **VBA-based user interface** integrated into Excel.
- A **64-bit DLL** compiled from C++, which is invoked directly by the VBA frontend.

> ⚠️ **Note**: This project is compatible only with **64-bit Windows systems**.

---

## ⚙️ Setup Instructions

Before running the program, follow these steps:

1. **Update VBA Paths**  
   Open the Excel file located at:  
   `C++\lookback\x64`

2. **Access the VBA Code**  
   In Excel:
   - Go to `Developer` → `Visual Basic`
   - Right-click on `ModernUserForm` → Select `View Code`
